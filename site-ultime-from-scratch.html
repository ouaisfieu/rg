Site ultime FROM SCRATCH

Le guide pas-à-pas pour faire ton premier (vrai) site, même si tu te considères comme une brêle en informatique.

1 dossier · 1 fichier · 1 sujet · 0 pression

L’objectif ici : que tu te dises, à la fin : « ok, j’ai vraiment un site à moi », même si tu pars de rien, nada, schnollebrol.

Tout ce que tu as à faire : suivre les étapes dans l’ordre. Si tu bloques, tu peux t’arrêter, respirer, revenir plus tard. On ne cherche pas la perfection. On cherche juste : ça marche.

Étape 0 – Ce qu’il te faut (vraiment pas grand-chose)

Pour faire ce site, il te faut :

  • Un ordinateur (Windows, Mac, Linux… peu importe).
  • Un navigateur web (Chrome, Firefox, Edge, Safari…).
  • Un éditeur de texte simple :
    • Windows : Bloc-notes
    • Mac : TextEdit (en mode texte brut)
    • Ou n’importe quel éditeur que tu aimes.
  • J’ai un ordinateur + un navigateur + un éditeur de texte ouvert.

Étape 1 – Créer un dossier pour ton site

On commence simple : on va créer un dossier qui contiendra ton futur site. Ce dossier pourra plus tard aller sur une clé USB, sur un autre PC, sur GitHub Pages…

  1. Ouvre ton gestionnaire de fichiers (Explorateur sur Windows, Finder sur Mac).
  2. Va dans un endroit où tu sais revenir (par exemple : Documents).
  3. Crée un dossier avec un nom simple, par exemple : mon-premier-site.
  • J’ai un dossier nommé mon-premier-site (ou équivalent).

Étape 2 – Créer ton premier fichier HTML

Un site web, c’est principalement des fichiers .html. On va en faire un seul, avec le strict minimum pour que ce soit un vrai site.

Pas-à-pas pour créer le fichier index.html
  1. Dans ton éditeur de texte, colle exactement ce qui suit :
<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Mon premier site</title>
</head>
<body>
  <h1>Bonjour, c’est mon premier site.</h1>
  <p>Je pars de rien et pourtant, cette page existe.</p>
</body>
</html>
  1. Dans ton éditeur, fais « Enregistrer sous… ».
  2. Va dans le dossier mon-premier-site.
  3. Donne comme nom au fichier : index.html (sans espace).
  4. Assure-toi que l’extension est bien .html (et pas .txt).
  • Dans mon dossier, je vois un fichier appelé index.html.

Étape 3 – Ouvrir ton site dans le navigateur

Maintenant, on va vérifier la magie : est-ce que ton « site » fonctionne déjà ?

  1. Ouvre le dossier mon-premier-site.
  2. Double-clique sur index.html.
  3. Ton navigateur devrait s’ouvrir et afficher le texte : « Bonjour, c’est mon premier site. Je pars de rien et pourtant, cette page existe. »
  • Quand je double-clique sur index.html, une page s’ouvre. 🎉

À partir de ce moment-là, tu as déjà un site. Sérieusement. Plein de choses sur le web sont juste des fichiers HTML ouverts par un navigateur.

Étape 4 – Mettre “toi” à la place du texte d’exemple

On va maintenant remplacer le texte par quelque chose qui parle de toi ou de ton sujet (peu importe lequel : projet, hobby, thèse, enquête, journal, etc.).

Que changer exactement dans le fichier ?
1. Rouvre index.html dans ton éditeur de texte.
2. Repère ces deux lignes : 
<h1>Bonjour, c’est mon premier site.</h1>
<p>Je pars de rien et pourtant, cette page existe.</p>
3. Remplace-les par quelque chose qui te ressemble, par exemple : 
<h1>Bienvenue sur mon coin d’Internet</h1>
<p>Ici, je vais parler de ce qui m’occupe la tête en ce moment.</p>
ou : 
<h1>Carnet de recherche (version très perso)</h1>
<p>Je note ici mes idées, mes questions et mes ratés. Pour l’instant, c’est juste pour moi.</p>
4. Enregistre le fichier, puis retourne dans ton navigateur et recharge la page (F5 ou bouton « Actualiser »).
  • Le texte que je vois parle désormais de MOI / de MON sujet.

Étape 5 – Ajouter un peu de mise en forme (sans paniquer)

On va ajouter un tout petit peu de style pour que ce soit plus agréable à regarder. Tu n’es pas obligé·e de tout comprendre, tu peux juste copier-coller.

Ajouter quelques styles dans <head>
1. Rouvre index.html dans ton éditeur.
2. Dans la partie <head>…</head>, juste avant </head>, colle ceci : 
<style>
  body {
    font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
    background-color: #0f172a;
    color: #e5e7eb;
    margin: 0;
    padding: 20px;
  }
  main {
    max-width: 700px;
    margin: 0 auto;
    background-color: #020617;
    border-radius: 16px;
    padding: 16px;
    border: 1px solid #1f2937;
  }
  h1 {
    font-size: 1.6rem;
    margin-bottom: 8px;
  }
  p {
    line-height: 1.6;
  }
</style>
3. Enregistre, puis recharge la page dans le navigateur.
4. Tu devrais voir ton texte avec un fond sombre plus propre.

Tu peux t’arrêter ici. Tu as un site simple, lisible, qui parle de toi. Le reste (plusieurs pages, navigation, BROL, GORK, etc.) pourra venir plus tard.

Étape 6 – (Optionnel) Ajouter une deuxième page et un mini-menu

Si tu te sens en forme, on peut passer de « un site = une page » à « un site = plusieurs pages ».

Créer une page2.html à partir de la première
1. Dans ton gestionnaire de fichiers, dans le dossier mon-premier-site :
  • copie le fichier index.html,
  • colle-le dans le même dossier,
  • renomme la copie en page2.html.
2. Ouvre page2.html dans ton éditeur et change le contenu au centre, par exemple : 
<h1>Page 2</h1>
<p>Ici, je mets des choses moins importantes, ou des notes en vrac.</p>
Ajouter un mini-menu entre les deux pages
Dans les deux fichiers (index.html et page2.html), juste sous la première ligne <h1>..., ajoute par exemple : 
<nav>
  <p>
    <a href="index.html">Accueil</a> ·
    <a href="page2.html">Page 2</a>
  </p>
</nav>
Enregistre, recharge les pages dans le navigateur, puis clique sur les liens.
  • Je peux aller de la page d’accueil à la page 2, et revenir en arrière.

Étape 7 – Et maintenant, on fait quoi avec ça ?

Tu peux utiliser cette mini-structure pour n’importe quoi :

  • un carnet de recherche,
  • un journal de bord,
  • un mini-site de projet,
  • un univers fictionnel (comme ta Vallée pixelisée),
  • un essai en plusieurs parties.

À partir d’ici, tu as trois chemins possibles :

  • Chemin 1 Rester sur « petit site simple » longtemps. Tu peux simplement remplir ces pages avec du texte.
  • Chemin 2 Commencer à organiser tes fichiers (PDF, images…) en créant plus tard un BROL 2.0 (une page qui liste tout).
  • Chemin 3 Transformer ce début en univers plus complexe (GORK, GROK-CORE, intranet, etc.).

Tu ne dois pas choisir maintenant. L’important : tu sais désormais créer un dossier, un fichier HTML, l’ouvrir, le changer, ajouter une page, faire un petit menu. C’est déjà une boîte à outils complète.

Petit récap’ (ce que tu sais faire maintenant)

  • Je sais créer un dossier pour un site.
  • Je sais créer un fichier .html et l’ouvrir dans un navigateur.
  • Je sais modifier le texte pour qu’il parle de moi / de mon sujet.
  • Je sais dupliquer une page et créer un mini-menu entre deux pages.
  • Je sais que je peux faire évoluer ça en BROL / intranet / univers.

Ce fichier site-ultime-from-scratch.html peut rester ton point de départ. Tu peux le garder à côté de tes autres pages comme pense-bête. Plus tard, on peut brancher dessus : BROL 2.0, intranet, univers cartoon, hub GROK, etc. Pour l’instant : si tu as un dossier + un index.html qui s’ouvre → tu es déjà dans le game.
