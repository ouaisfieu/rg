---

## 1. **Objet du rapport**

Ce rapport présente :

* l’état d’avancement opérationnel de l’Organisation,
* la structuration interne en cours,
* les productions réalisées,
* les besoins en ressources humaines,
* les risques identifiés,
* les prochaines étapes à consolider.

Ce document vise un niveau professionnel permettant un contrôle externe, un audit, ou une évaluation partenariale.

---

# 2. **Contexte général**

## 2.1 Nature du projet

L’Organisation se positionne comme une **entité sociale innovante** visant :

* l’éducation citoyenne,
* le renforcement du pouvoir d’agir,
* l’analyse critique des institutions,
* la création d’outils pédagogiques avancés,
* l’expérimentation méthodologique (tests, parcours, labs).

Elle agit comme une **structure autonome**, multi-projets, distribuée, utilisant massivement :

* les outils open source,
* les sites statiques (Hugo, Grav, GitHub Pages),
* la veille stratégique,
* les dispositifs pédagogiques interactifs.

## 2.2 Enjeux sociétaux abordés

Les thématiques au cœur du projet :

* éducation permanente / éducation populaire en Belgique,
* fracture numérique,
* compréhension des systèmes institutionnels,
* autodéfense intellectuelle,
* guerre narrative (désinformation, influence, cadrage médiatique),
* empowerment des publics fragilisés (chômage, maladie, précarité).

# 6. **Risques identifiés**

## 6.1 Risques internes

| Risque                               | Description                                      | Niveau |
| ------------------------------------ | ------------------------------------------------ | ------ |
| Charge mentale                       | Trop de projets simultanés                       | Élevé  |
| Dépendance à 1 personne              | Gouvernance fragile                              | Élevé  |
| Sur-engagement des publics précaires | Risque éthique                                   | Élevé  |
| Dispersion                           | Multiplication des prototypes sans consolidation | Moyen  |
| Documentation insuffisante           | Maintenance compliquée                           | Moyen  |

## 6.2 Risques externes

| Risque                           | Description                                | Niveau       |
| -------------------------------- | ------------------------------------------ | ------------ |
| incompréhension institutionnelle | Projet atypique difficile à “classer”      | Moyen        |
| alignement juridique             | Asbl de fait / SAS informelle → zone grise | Moyen        |
| financement                      | Pas encore de modèle stable                | Élevé        |

# 7. **Opportunités**

* forte traction citoyenne (éducation permanente / OSINT / empowerment),

# 8. **Feuille de route (12 mois)**

## 8.1 Phase 0 → 1 (0–3 mois)

* recruter cellule veille
* finaliser 3 tests pédagogiques complets
* stabiliser portail documentaire
* consolider rôle Tech & Infrastructure

## 8.2 Phase 1 (3–6 mois)

* lancer 2 partenariats pilotes (écoles, asbl, commune)
* installer le Lab Pédagogie
* documenter les méthodes et canevas

## 8.3 Phase 2 (6–12 mois)

* ouverture du Comité éthique
* lancement du Lab IA
* expérimentation terrain (quartiers / ateliers publics)
* version publique “v1” du projet (stabilisée)
