Bienvenue sur la plateforme AGENCE X

Analyse. Synthèse. Fiction assumée.

Ce site simule l’interface publique d’une agence de renseignement. Il est conçu pour s’entraîner à structurer des informations, rédiger des notes et manipuler un intranet… sans aucune donnée réelle.

Voir les missions fictives Accès intranet de démonstration

Tu peux utiliser ce fichier comme base pour ton propre site : modifie simplement les textes, les missions, l’équipe et les champs de contact. Tout tient dans ce seul index.html, idéal pour une clé USB.

Missions fictives

Les missions ci-dessous sont des scénarios d’entraînement. Tu peux les remplacer par tes propres cas d’école (veille, analyse de discours, fact-checking, etc.).

MX-01 – Veille médias

Code : OUVERT

Cartographier les sources d’information autour d’un sujet donné (articles, posts, communiqués).

Livrable : liste de sources + premier schéma d’acteurs.

MX-02 – Note de synthèse

Code : EN COURS

Transformer un dossier de documents en une note de synthèse d’une page pour un décideur pressé.

Livrable : note structurée (contexte, enjeux, options).

MX-03 – Cartographie d’acteurs

Code : ARCHIVÉ

Exemple de mission terminée : identification des principaux acteurs sur un thème précis.

Livrable : carte + fiche synthèse.

Cellule d’analyse (alias fictifs)

L’équipe ci-dessous est entièrement fictive. Tu peux la remplacer par de vraies personnes ou par des rôles (ex. « cellule veille », « cellule juridique »).

ALPHA

Responsable analyse stratégique
Coordonne les missions, valide les synthèses finales, prépare les briefs pour la direction.

BÉTA

Analyste veille & cartographie
Collecte les sources, identifie les tendances, construit les cartes d’acteurs et les lignes de force.

GAMMA

Rédacteur·rice de synthèse
Transforme la masse d’information en notes claires, adaptées au temps de lecture disponible.

DELTA

Opérations & sécurité
Supervise les accès à l’intranet, s’assure que les données utilisées restent compatibles avec l’objectif pédagogique.

À propos de cette plateforme

        

          AGENCE X est une simulation : tout est pensé pour
          l’apprentissage (cours, ateliers, jeux de rôle, prototypage de
          dispositifs d’analyse).
        

        

          Tu peux modifier librement ce fichier, en gardant en tête : pas de
          données réelles sensibles, pas d’usage illégal. Le but est de
          comprendre les logiques d’un site d’agence et d’un intranet, pas de
          faire de la surveillance.
