BROL 2.0 – ton catalogue de fichiers

Ici, tu ranges tous tes fichiers (PDF, images, vidéos, audio, liens, notes…) dans une seule interface, avec des filtres par type, catégorie et tags. Le tout est statique : c’est toi qui déclares les fichiers dans un tableau JavaScript.

Comment construire ton BROL pièce par pièce

Tu peux partir de rien. Ce fichier est déjà un prototype qui fonctionne. Tu as juste à remplir le tableau brolItems avec tes vrais fichiers.

  • Étape 1 – Crée le dossier

    Crée un dossier, par ex. BROL-2.0/. Mets ce fichier sous le nom index.html à l’intérieur.

  • Étape 2 – Mets tes fichiers à côté

    Mets dans le même dossier tes PDF, images, sons, etc. Exemple : dystopie.pdf, plaidoyer-jp.pdf, photo-mur.jpg, etc.

  • Étape 3 – Déclare-les dans brolItems

    En bas de ce fichier, dans le script JavaScript, trouve le tableau brolItems et ajoute une entrée par fichier.

    { id: "dystopie", name: "Dystopie – annexe thèse", type: "pdf", category: "these", path: "dystopie.pdf", tags: ["annexe", "stic", "dystopie"], description: "PDF local placé à côté de index.html." }
  • Étape 4 – Teste la prévisualisation

    En cliquant sur une carte :

    • les PDF et images s’ouvrent en modale dans le navigateur,
    • les liens avec type: "link" sont ouverts en iframe (YouTube, Spotify) ou dans un nouvel onglet,
    • tu vois en bas de la modale le snippet à copier-coller pour ajouter des entrées similaires.
  • Étape 5 – Connecter à tes autres sites

    Tu peux déclarer ici des liens vers :

    • OPÉRATION MILOU (page thèse / MMO),
    • ton site détective,
    • ton intranet lambda, ton hub, ta FAQ.
    { id: "milou-site", name: "Site OPÉRATION MILOU", type: "link", category: "these", path: "https://TON-URL-GITHUB-PAGES", tags: ["site", "milou"], description: "Lien vers le site MILOU publié sur GitHub Pages." }

Tout ce que tu as fait avant (MILOU, intranet, moteur, FAQ, console…) peut être intégré ici, soit comme fichiers locaux (autres .html), soit comme liens externes.
