## 🔰 0. L’OPÉRATION MILOU (résumé)

L’**OPÉRATION MILOU** est une cellule socio-technique expérimentale qui explore une question discrète :
**→ Peut-on mobiliser des principes anarchistes pour réparer, orienter ou neutraliser des effets destructeurs du capitalisme numérique ?**

Ce dépôt contient :

* le **site public** (GitHub Pages)
* le **journal de bord** (worklog)
* les **annexes PDF**
* la **méthode 6·4·2**
* et la **gamification intégrale du projet**, pensée comme un **MMORPG IRL** pour rendre la recherche vivable.

---

# 🧪 1. Le cadre scientifique (STIC)

**Domaine :** Sciences et Technologies de l’Information et de la Communication (STIC).
**Approche :** socio-technique, critique, méthodologique, appliquée.
**Objet :** organisations numériques, communs, gouvernance, infrastructures, plateformes, idéologies critiques.

### ❓ Question centrale

> **Comment des dispositifs inspirés de l’anarchie (entraide, autogestion, communs, non-domination) peuvent-ils stabiliser ou corriger certaines dynamiques du capitalisme numérique — dans des organisations socio-techniques réelles ?**

# 🎮 2. Le projet… mais comme un MMORPG IRL

## 🎭 2.1. Classes de personnages (IRL)

Chaque membre de l’Opération Milou peut choisir une **classe IRL**, selon ses compétences :

| Classe                      | Stat principal | Rôle                            | Atouts                         |
| --------------------------- | -------------- | ------------------------------- | ------------------------------ |
| **Chercheur·se Nomade**     | INT            | Analyse, littérature            | +20% lecture rapide            |
| **Ingénieur·e du Bazar**    | TECH           | Prototypage                     | +15% debug mental              |
| **Scribe Cryptique**        | WIS            | Rédaction, distillation         | -20% dégâts de jargon          |
| **Samouraï Administratif**  | CON            | Normes, RGPD, régulation        | +30% résistance bureaucratique |

Libre à toi d’en créer d’autres (classe “GuildMaster”, “Archiviste du Chaos”, etc.).

## 🗺️ 2.2. La carte du monde (IRL)

Le *monde* de #milou se découpe en **zones** :

* **Zone 1 : Le Bazar Théorique** (anarchie, capitalisme, communs, cyberpunk, dystopies)
* **Zone 2 : Les Donjons Socio-Tech** (projets libres, collectifs, plateformes alternatives)
* **Zone 3 : Les Marécages Institutionnels** (régulation, politiques publiques, droit)
* **Zone 4 : Le Réseau-Souterrain** (infrastructures, protocoles, serveurs)
* **Zone 5 : La Cour des Communs** (gouvernance distribuée)
* **Zone 6 : L’Académie des Sciences** (rédaction de la thèse)

Chaque zone correspond à un **F** de la méthode 6·4·2.

## 📘 2.3. La méthode 6·4·2 (version RPG)

### 🎲 **6 Fils directeurs (storyline)**

1. Gouvernance
2. Propriété
3. Infrastructures
4. Rémunération
5. Conflit & soin
6. Reproductibilité

→ *Ce sont les arcs narratifs du jeu.*

### 🧩 **4 Axes de terrain (maps)**

* Axe A — Théories & récits
* Axe B — Projets & collectifs
* Axe C — Infrastructures numériques
* Axe D — Régulation & institutions

→ *Ce sont les zones explorables.*

### ⚔️ **2 Niveaux d’analyse (boss tiers)**

* **Niveau 1 : Micro** (équipe, projet, outil) → *mini-boss*
* **Niveau 2 : Macro** (économie, régulation, imaginaire) → *boss de zone*

## 🧭 2.4. Quêtes principales

Les **quêtes principales** suivent strictement la méthodologie scientifique :

* 🔎 **QP1 — Définir la question de recherche**
* 📚 **QP2 — Cartographier les théories**
* 🧪 **QP3 — Choisir 3 à 5 cas d’étude**
* 🩻 **QP4 — Analyser les dispositifs socio-techniques**
* 🧱 **QP5 — Proposer des modèles reproductibles**
* 📜 **QP6 — Rédiger la thèse**

Chaque quête est liée à des commits + issues GitHub.

## 🕹️ 2.6. XP, niveaux et progression

### Gagner de l’XP (exemples adaptés à la recherche)

* +10 XP → 1 page lue dans une annexe PDF
* +20 XP → issue ouverte avec description claire
* +30 XP → commit qui améliore le site
* +40 XP → note de terrain rédigée
* +50 XP → analyse comparative
* +100 XP → version stable d’un chapitre

### Palier de niveaux

* **N1 : Novice de la Méthode** — 0–150 XP
* **N2 : Cartographe des Concepts** — 150–500 XP
* **N3 : Fouilleur de Donjons Socio-tech** — 500–1000 XP
* **N4 : Architecte Numérique** — 1k–3k XP
* **N5 : Maître Communard** — 3k–6k XP
* **N6 : Docteur·e du Chaos Contrôlé** — 6k+ XP
