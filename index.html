Comment ajouter tes propres pages au dashboard

Tout est piloté par un tableau modules en bas du fichier. Chaque entrée décrit une page (fichier local) ou une vue spéciale.

  1. Crée ton fichier HTML (ex. mon-projet.html) dans le même dossier.
  2. Dans dashboard.html, cherche const modules = [.
  3. Ajoute-y un bloc comme ceci :
{
  id: "mon-projet",
  title: "Mon projet secret",
  file: "mon-projet.html",
  category: "univ",        // base, brol, univ, intra, ia, meta
  kind: "univers perso",
  description: "Description courte de ce que contient cette page."
},
  1. Enregistre, recharge dashboard.html dans ton navigateur.
  2. Ta nouvelle entrée apparaît dans la liste, cliquable.

Comment ajouter / modifier un embed

Tu peux ajouter un bouton “embed” qui envoie n’importe quel URL dans le viewer : YouTube, PDF, image, autre page HTML, etc.

  1. Repère la section const embeds = { ... } dans le script.
  2. Ajoute par exemple :
customDoc: {
  label: "Mon PDF thèse",
  url: "ma-these.pdf",
  description: "Version locale de ma thèse."
}
  1. Ajoute un bouton dans la partie HTML des embeds :
<button type="button" class="embed-btn" data-embed="customDoc">
  <span class="icon">📄</span> Mon PDF thèse
</button>
  1. Clique sur ton bouton → le PDF se charge dans le viewer.
