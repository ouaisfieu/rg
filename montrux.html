Logiciels Incontournables

Un tour d’horizon des outils qui tiennent ton écosystème CCPLC / Organisation debout : les indispensables, les alternatives, et quelques pépites cachées à débloquer via un quizz.

🔧 Les logiciels incontournables (kit de base)
À installer sur ta machine principale & sur ta clé USB (si possible portable).

Navigation & web

🦊Firefox / Brave / Chromium
Niveau : débutant

Ton portail sur le web. Sert à tout : veille, tests, accès à ton instance.

  • Extensions privacy (uBlock, privacy badger…)
  • Profils séparés : perso / projet / expérimentation
📰Lecteur RSS (ex. Fluent Reader)
Niveau : confirmé

Pour centraliser ta veille citoyenne (flux d’actu, blogs, institutions…).

  • Categoriser par thèmes : info, tech, local, veille
  • Connecté à tes dossiers & tests de recrutement

Organisation & notes

📓Obsidian
Niveau : débutant → expert

Le cerveau externe du projet : notes, liens, cartes mentales, suivi des dossiers.

  • Un coffre-fort “Organisation” dédié
  • Un coffre-fort “Apprentissage perso”
📂Explorateur de fichiers + Sync (ex. Syncthing)
Niveau : confirmé

Gérer proprement le dossier de ton instance (html, pdf, images, etc.).

  • Arborescence claire pour la clé USB
  • Synchro entre machines si besoin

Création, code & sites statiques

🧑‍💻VS Code / VSCodium
Niveau : débutant+

Éditer proprement .html / .md / .css et scripts JS.

  • Coloration syntaxique
  • Extensions Markdown, HTML, Git
🌐Git & GitHub Desktop
Niveau : confirmé

Versionner ton kit de pages et le publier sur GitHub Pages / Vercel.

  • Un dépôt “instance-locale”
  • Un dépôt “public” pour partager

Multimédia & confort

🎥VLC
Niveau : débutant

Lire toutes les vidéos (tutos, docs, archives) sans se battre avec les formats.

📄LibreOffice / OnlyOffice
Niveau : débutant

Bureautique classique : rapports, fiches, tableaux, impressions.

Pour explorer des alternatives (libres, payantes, multi-plateformes), tu peux passer par AlternativeTo.net. Tape par ex. “Obsidian”, “VS Code”, “Firefox” pour voir les options.

💡 Tips par niveau & easter eggs
Clique, teste, joue avec les niveaux pour voir ce qui te parle.
Débutant safe mode
  • Commence avec Firefox + bloqueur de pub. Rien que ça change déjà la donne.
  • Installe Obsidian et écris 1 note / jour, sans te juger.
  • Garde un seul dossier “CCPLC” bien rangé sur ton bureau.
Confirmé level up
  • Crée un vault Obsidian “Organisation” lié à ton instance de pages HTML.
  • Utilise un lecteur RSS pour suivre 10–20 sources max, triées par thèmes.
  • Versionne ton dossier via GitHub Desktop (même en privé).
Pro / Hacker bienveillant secret sauce
  • Teste un Linux en live USB pour tes sessions “veille & développement”.
  • Auto-héberge un FreshRSS ou utilise un service fiable pour ta veille.
  • Automatise des sauvegardes chiffrées (GnuPG + cloud + disque externe).

🌐 Place des logiciels dans l’écosystème

Si on simplifie, ton écosystème se structure en quatre couches :

  • 1. Interface : navigateur, obsidian, lecteurs, outils de travail quotidien.
  • 2. Contenu : pages HTML, dossiers PDF, notes, images, vidéos.
  • 3. Infrastructure : disque dur, clé USB, hébergement web, Git.
  • 4. Gouvernance : toi, ton collectif, les règles du jeu & le cadre éthique.

Les logiciels ne sont pas des “fins en soi” : ce sont des prothèses d’intelligence. Le test, les jeux et les dossiers te servent à garder la main sur l’outil, pas l’inverse.
