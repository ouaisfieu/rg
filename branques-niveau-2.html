Branques – Niveau 2

Tu as ton fichier scratchy-index.html qui fonctionne. Bravo. Maintenant, on construit un **petit site complet très simple** :

1. Une page d’accueil 2. Une page “Notes / Idées / Bordel organisé” 3. Une page “Étagère à fichiers” 4. Des liens pour aller et revenir

Rien de plus. Rien de moins. Juste assez pour que tu saches : « ok, je peux naviguer dans mon site comme un humain normal ».

📁 Étape 1 — Vérifie ton dossier

Dans ton dossier (par ex. mon-premier-site), tu dois avoir :

✔️ scratchy-index.html

Si oui → parfait. Sinon → retourne à la page précédente, et reviens ici.

📝 Étape 2 — Créer la “page 2”

On copie ton fichier et on le transforme en carnet d’idées.

  1. Copie ton fichier scratchy-index.html.
  2. Colle-le dans le même dossier.
  3. Renomme la copie → notes.html

Maintenant ouvre notes.html dans ton éditeur et change le contenu du centre :

<h1>Mes notes</h1>
<p>Ici je note tout ce qui me passe par la tête.</p>
<p>C’est le début d’un cerveau externe, version branque.</p>

📚 Étape 3 — Créer une “étagère à fichiers”

Une étagère, c’est juste une page où tu listes ce que tu veux : PDF, images, liens, vidéos…

  1. Crée un nouveau fichier → etagere.html

Mets-y ceci :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8" />
  <title>Étagère</title>
  <style>
    body { background:#0f172a; color:#e5e7eb; font-family:sans-serif; padding:20px; }
    a { color:#38bdf8; }
  </style>
</head>
<body>
  <h1>Mon étagère</h1>
  <p>Les fichiers, les images, les trucs importants.</p>

  <ul>
    <li><a href="docs.pdf">Mon PDF (exemple)</a></li>
    <li><a href="photo.jpg">Ma photo (exemple)</a></li>
  </ul>

  <p><a href="scratchy-index.html">Retour</a></p>
</body>
</html>

Tu peux ajouter des vrais fichiers dans ton dossier ou laisser les exemples, c’est OK.

🔗 Étape 4 — Ajouter les liens dans la page d’accueil

Ouvre ton scratchy-index.html. Repère l’endroit où il y a ton titre et ton texte.

Ensuite ajoute ceci juste en dessous :

<p><a href="notes.html">Aller à mes notes</a></p>
<p><a href="etagere.html">Aller à mon étagère</a></p>

🔁 Étape 5 — Ajouter les liens de retour

Ouvre notes.html et ajoute à la fin : 

<p><a href="scratchy-index.html">Retour à l’accueil</a></p>

Même chose dans etagere.html (si ce n’est pas déjà fait).

🎉 Bravo — Tu as un véritable mini-site

✔️ 3 pages ✔️ Navigation ✔️ Un endroit pour écrire ✔️ Une étagère pour stocker ✔️ Une page d’accueil qui tient tout

C'est exactement la structure de base de n’importe quel site web au monde.

Et tu l’as fait sans outils compliqués.
