📜 Checklist Hardcore — “Tu n’es pas ton code, tu es ce que tu fais avec”.

Tu valides une instance hardcore si ton propre index.html inclut :

  • ✔ Une intro façon Blade Runner 1982 : lente, lourde, poétique, meta.
  • ✔ Un mode secret à débloquer façon Konami Code (↑↑↓↓←→←→BA).
  • ✔ Un thème NEON GRID inspiré de Tron Legacy.
  • ✔ Une citation obscure mais pertinente d’Asimov, Herbert ou Gibson.
  • ✔ Un “Test Voight-Kampff” maison (3 questions sur l’empathie).
  • ✔ Un menu qui apparaît en glitch façon Mr Robot.
  • ✔ Un mode “Ministère de la Vérité” de 1984 (affiche une version trafiquée des pages).
  • ✔ Un bouton “RED PILL” qui désactive l’UI et montre le code brut.
  • ✔ Une zone “Souterrain” façon The Wire, que l’on ne trouve pas sans inspecteur.
  • ✔ Un clin d’œil à Sa Majesté des Mouches (pouvoir, chaos, tribu).
  • ✔ Un générateur de noms d’Organisation façon Fondation d’Asimov.
  • ✔ Un système d’“aptitudes légendaires” façon Skyrim mais version citoyenne.
  • ✔ Une mention cachée “The cake is a lie” dans un commentaire HTML.
  • ✔ Un QR code menant… à un autre QR code (référence Inception).

💾 Easter Eggs suggérés

  • 🔒 Un faux fichier “danger.txt” qui n’est qu’un poème sur la liberté.
  • 🔧 Un mode “God Mode” qui ne fait… absolument rien. (référence Doom)
  • 🎣 Un faux écran de terminal qui exécute des lignes aléatoires (comme dans Jurassic Park).
  • 🔁 Une boucle GIF de glitch inspirée d’Akira.
  • 🐇 Une page “SUIVRE LE LAPIN” cachée façon Matrix.
  • 🔭 Une fausse mission du “Projet MK-Ultra” (mais en version citoyenne douce).
  • 📡 Une page “Transmission reçue” façon Contact (1997).
