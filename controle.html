Pour adapter ce panneau à ta clé / ton Git :

  • Ouvre ce fichier console.html dans un éditeur de texte.
  • Dans la section <div id="linksGrid">, ajoute, supprime ou modifie les cartes.
  • Change les href="..." pour pointer vers tes propres pages.
  • Tu peux dupliquer un bloc <a ...><article ...>… pour créer un nouveau lien.

Tu peux aussi cloner cette console et en faire une version spéciale “Conspi”, “Sharky”, “École”, “Élus”, etc., en gardant la même logique.
